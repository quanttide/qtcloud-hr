# 量潮人事云预览版使用说明

本文档面向内部同事，说明如何使用当前已上线的量潮人事云预览版。当前版本用于熟悉页面、验证招聘工作流和 dry-run 操作，不会真实读取 HR 邮箱、发送邮件或下载简历附件。

## 访问入口

- 线上地址：<https://human.cloud.quanttide.com/>
- 当前前端版本：`studio/v0.1.0-alpha.3`
- 当前后端版本：`provider/v0.1.3`
- Provider API：`https://qtcloudman-prod-eqpdghspoh.cn-hangzhou.fcapp.run`

## 当前可用范围

| 功能 | 当前状态 | 说明 |
|------|----------|------|
| 打开人事云工作台 | 可用 | 通过 `human.cloud.quanttide.com` 访问 |
| 查看总览、计划、培训、绩效、薪酬、关系页面 | 可用 | 当前多为演示/样例数据 |
| 招聘页面候选人列表 | 可用 | 预览环境当前为空列表，真实同步关闭 |
| 生成招聘报告 | 可用 | dry-run 报告，不读取真实邮箱 |
| 拉取新邮件 | 仅 dry-run | 不读取 `hr@quanttide.com` 邮箱 |
| 发送问卷、实训邀约、笔试、面试通知 | 仅 dry-run | 不真实发信，只验证按钮和接口流程 |
| 打开简历附件 | 暂不开放真实动作 | 真实下载依赖 HR 邮箱认证，当前默认关闭 |

## 使用步骤

### 1. 打开工作台

1. 在浏览器访问 <https://human.cloud.quanttide.com/>。
2. 等待 Flutter Web 应用加载完成。
3. 左侧导航可切换总览、计划、招聘、培训、绩效、薪酬、关系等模块。

### 2. 进入招聘页面

1. 点击左侧导航中的“招聘”。
2. 页面顶部显示“招聘筛选网关”。
3. 确认 `dry_run` 开关保持打开。预览版请不要关闭该开关。

### 3. 拉取新邮件 dry-run

1. 在招聘页面点击“拉取新邮件”。
2. 预览版后端会返回 dry-run 结果。
3. 当前不会访问真实 HR 邮箱，因此候选人列表可能仍为空。

预期结果：页面提示“收件箱 dry_run 已完成，未读取真实邮箱”。

### 4. 生成招聘报告 dry-run

1. 在招聘页面点击“生成报告”。
2. 后端生成 dry-run Markdown 报告。
3. 页面展示报告结果。

预期结果：报告状态为 `dry_run`，内容会提示未读取真实邮箱。

### 5. 体验候选人动作按钮

如果页面上已有候选人数据，可以在候选人详情区体验以下按钮：

- 发送问卷
- 发送实训邀约
- 发送笔试
- 生成面试通知

当前这些按钮在 dry-run 模式下只验证流程，不会向候选人发送邮件。

## 预览版限制

1. 当前不是正式多人协作生产版，没有接入企业级登录和权限系统。
2. 当前后端生产配置保持 `QTCLOUD_HUMAN_ALLOW_REAL_RECRUITMENT_ACTIONS=false`，真实读信、发信和简历下载都会被拒绝。
3. 招聘候选人状态当前仍是服务端内存状态，不适合多人长期协作记录。
4. 当前页面中的 `X-Operator` 和 `X-Recruitment-Permission` 只是开发期请求上下文，不能作为正式权限体系。
5. 如果要开放真实招聘动作，需要先补齐认证、授权、持久化存储和 HR 邮箱认证态。

## 常见问题

### 页面能打开，但招聘列表为空

这是预期现象。预览版默认不读取真实邮箱，候选人列表可能为空。

### 点击“生成报告”后显示 dry-run

这是预期现象。预览版用于验证报告生成链路，不读取真实 HR 邮箱。

### 点击真实动作提示被禁用

这是预期保护。后端当前会拒绝真实读信、发信和简历下载，避免预览期间误操作候选人邮箱。

### 页面加载旧版本

可以先强制刷新浏览器页面。如果仍旧异常，等待 CDN 刷新生效后再访问。

### 页面提示 provider API 不可用

请确认访问的是 <https://human.cloud.quanttide.com/>，并把问题反馈给维护者。当前前端发布产物已经内置 provider API 地址。

## 后续转正式版前必须补齐

1. 接入不可伪造的登录和权限体系，例如 API 网关鉴权、企业 SSO 或服务端 token 校验。
2. 将候选人列表、人工状态和动作日志持久化到数据库或对象存储。
3. 明确 HR 邮箱访问方案：稳定的 `lark-cli` 认证态，或改为服务端直接调用飞书 OpenAPI。
4. 开启真实动作前，限定可操作人员名单，并保留审计日志和快速关闭开关。
